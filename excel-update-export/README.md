# Оновлення вкладки Export_* у файлах менеджерів

Макрос `UpdateExport.bas` бере нові дані з файлу `data_XX.xlsx` (лист `Export`)
і за один запуск оновлює вкладку `Export_<Прізвище>` в усіх файлах менеджерів.
Введені цілі (колонка **O «Ціль (ввід)»**) і примітки (колонка **S**) зберігаються.
Колонка **N «Сумма»** — це формула, вона перераховується з колонки O автоматично.

## Що робить макрос з кожним файлом

1. Робить резервну копію у підпапку `Backup_<дата_час>` поруч з файлами.
2. Визначає менеджера за колонкою P (якщо вона порожня — за прізвищем у назві вкладки).
3. Запам'ятовує всі заповнені клітинки O і S за ключем
   **OWN_ID + Комплекс + КатегоріяТГ**.
4. Бере з data всі рядки цього менеджера (колонка «Менеджер клієнта»).
5. Додає або видаляє рядки у вкладці так, щоб їх було стільки ж, скільки в data.
   Рядки вставляються/видаляються всередині таблиці, тому всі посилання
   (`$O$15:$O$4805`, `$Y$4805`, підсумок у рядку 13, умовне форматування,
   автофільтр, вкладки «Підсумки» і «Для завантаження плану») Excel зсуває сам.
6. Записує нові значення в A:L, P:R і протягує формули M, N, T:AE з рядка 15.
7. Повертає цілі в O: у рядок з тим самим OWN_ID + Комплекс + Категорія, а якщо
   такого комплексу вже немає — у перший рядок пари OWN_ID + Категорія
   (колонка N підсумовує по парі «Власник + Категорія», тож сума не зміниться).
8. Перераховує, зберігає й закриває файл.

Наприкінці відкривається книга «Звіт»: по кожному файлу — скільки рядків
було/стало і скільки цілей перенесено. Якщо для якоїсь цілі клієнта
чи категорії в нових даних немає, вона виводиться списком (значення не губиться —
воно є в резервній копії).

Відповідність колонок data → Export:

| Export | data |
|---|---|
| A OWN_ID | OWN_ID |
| B Власник | Власник |
| C Сфера діяльності | Сфера діяльності |
| D Комплекс | Комплекс |
| E Потенціал | Потенціал |
| F КатегоріяТГ | КатегоріяТГ |
| G 2025 повний | 2025 всього |
| H / I / J 1–3 кв 2026 | 1кв / 2кв / 3кв 2026 |
| K 2026 всього | 2026 фільтр |
| L Ціль (3 квартали) | Ціль фільтр |
| P Менеджер, Q Год, R Квартал | менеджер з data, рік і квартал зі старого файлу |

Колонка «4кв 2026» з data не використовується, бо у вкладці Export її немає.
Якщо порядок колонок у вивантаженні зміниться, поправте функцію `ExportMap`
і константи `D_*` на початку модуля.

## Як встановити (один раз)

1. Створіть нову книгу Excel і збережіть її як **«Книга Excel з підтримкою макросів» (.xlsm)**,
   наприклад `Оновлення Export.xlsm`.
2. `Alt+F11` → меню **File → Import File…** → оберіть `UpdateExport.bas`.
   (Або **Insert → Module** і вставте вміст файлу без першого рядка `Attribute VB_Name…`.)
3. Збережіть книгу.

> Якщо замість українських написів у вікнах бачите `????`, у Windows
> увімкніть українську для «Мови програм, що не підтримують Юнікод»
> (Панель керування → Регіон → Адміністративні). На роботу макросу це не впливає.

## Як запускати щоразу, коли приходить новий data

1. Закрийте всі файли менеджерів.
2. Відкрийте `Оновлення Export.xlsm`, натисніть `Alt+F8` → `UpdateExportSheets` → **Run**.
3. Оберіть файл `data_XX.xlsx`.
4. Оберіть файли менеджерів (у вікні можна виділити всі 20 через `Ctrl+A`).
5. Дочекайтеся повідомлення «Готово» і перегляньте книгу «Звіт».

Один файл обробляється від кількох секунд до хвилини (найдовше — перерахунок формул
COUNTIFS на великих вкладках).
